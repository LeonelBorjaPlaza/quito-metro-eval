# Quito Metro Air Quality

Local station-level analysis of the impact of the Quito Metro Line 1 opening on air quality, using AugSynth and Synthetic Difference-in-Differences (SDID) with REMMAQ ground-station data.


## Overview

This repository contains the local-scale analysis component of the Quito Metro air quality evaluation. Eight REMMAQ monitoring stations are used to estimate the impact of metro opening on four pollutants: PM2.5, NO2, CO, and SO2. Centro is the primary treated station; Belisario is included in the donor pool of the preferred specification because it lies near the corridor but exhibits substantially less direct exposure.

The September to December 2024 nationwide electricity blackout (Phase 3) creates a structural break that affects synthetic control identification. AugSynth runs on the full panel with sub-period ATTs computed post hoc. SDID runs on a donut panel that excludes blackout weeks, because its weighting depends on post-period composition.

## Methods

Twelve specifications per pollutant: four treatment configurations crossed with three methods.

Treatment configurations:

1. Centro and Belisario co-treated.
2. Belisario treated, Centro dropped.
3. Centro treated, Belisario dropped from the panel.
4. Centro treated, Belisario in donor pool (preferred, denoted with suffix "b").

Methods: SDID (donut panel), AugSynth (full panel), AugSynth with two-way fixed effects.

The four configurations are reported jointly in the main results table to address SUTVA concerns from Belisario's proximity to the corridor. The preferred specification is justified by the alternative configurations rather than asserted.

Sample: weekday peak hours (7-9 and 17-19), December 2022 onwards.

## Reproducing the analysis

Place raw data in `data/raw/remmaq/` (see "Data" below) and restore the R environment with renv. Then from the project root:

```r
source("code/master.R")
```

This regenerates all tables in `output/tables/`, figures in `output/figures/`, and diagnostics in `output/diagnostics/` from raw data.

Each per-pollutant setup script begins with `set.seed(12345)` to ensure deterministic conformal inference. To verify reproducibility, run `master.R` twice in fresh R sessions and `diff` the resulting `results_primary_specs.csv` files; they should be byte-identical.

## Data

Raw REMMAQ data is gitignored. To reproduce, download station-level hourly data from the Quito open data portal for the following stations and place into `data/raw/remmaq/`:

Belisario, Carapungo, Centro, Cotocollao, Guamani, Los Chillos, San Antonio, Tumbaco.

Pollutants required: PM2.5, NO2, CO, SO2. Time range used in the analysis: November 2022 onwards.

## Reproducibility

R version and package versions are pinned via renv. To restore the exact environment:

```r
renv::restore()
```

The seed `12345` is set at the top of each per-pollutant setup script. Determinism has been verified by running `master.R` in two separate fresh R sessions and confirming byte-identical outputs in `results_primary_specs.csv`.
